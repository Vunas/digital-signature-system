Bước 1: Chọn File PDF

Kéo thả file PDF vào đây

Tính năng nổi bật

  • Chữ ký hiển thị (Visible Signature): Tự động đóng dấu mộc chứa thông tin chữ ký ở góc dưới cùng file PDF.
  • Timestamp Authority (TSA): Gắn thời gian chuẩn quốc tế vào chữ ký chống chối bỏ. Fallback về Local time nếu mất mạng.

Khóa này được cấu hình Zero-Knowledge. Bạn cần nhập mật khẩu để giải mã ký tài liệu.

Khóa này được lưu cục bộ. Hãy tải file Private Key của bạn lên để thực hiện ký.
